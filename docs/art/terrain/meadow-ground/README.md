# Meadow ground

`quiet.png` and `dark.png` provide meadow ground. `materials.json` selects ordinary, dark and deep
meadow, earth and supported transitions. Both outputs are 512×512 panel exports of `master.png`.

Run `npm run art -- build terrain/meadow-ground`, then `npm run art -- review terrain/meadow-ground`. Publish the approved candidate with `npm run art -- publish terrain/meadow-ground`.
