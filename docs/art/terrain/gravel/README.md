# Gravel transitions

`gravel.png` supplies rocky transition overlays through the [mountain
bindings](../mountains/rock-materials.json). Export takes the left 627×627 panel region of
`master.png` at y=313 and reduces it to 512×512.

Run `npm run art -- build terrain/gravel`, then `npm run art -- review terrain/gravel`. Publish the approved candidate with `npm run art -- publish terrain/gravel`.
