# Mountains

`mountains.png` supplies a continuous 8-column by 11-row rocky ground composition.
`rock-materials.json` binds mountain patterns and uses the [gravel material](../gravel/README.md)
for mountain transitions. Map elevation supplies the landform.

Run `npm run art -- build terrain/mountains`, then `npm run art -- review terrain/mountains`. Publish the approved candidate with `npm run art -- publish terrain/mountains`.
