# Appearances

The four `man-*` packages share `../shared/body/`. Each owns its complete head, socket,
recipe, layout and selected strips. `woman-blonde/` additionally owns her body and clothing preparation.

Keep IDs synchronized with runtime folders, `selection.json`, `job-selection.json` and `catalog.json`.
Use [PIPELINE.md](../PIPELINE.md) for export and [MODULARITY.md](../MODULARITY.md) for fitting.
The [board](../index.html) links each appearance to a playable map.
