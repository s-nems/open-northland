# Carpenter hammer

`concept/` owns the painted input and prompt; `model/model.glb` is the textured render source.
Request parameters and API receipts sit beside the model.

`socket.json` defines the male body's right-hand grip, local rotation, palm offset and head scaling.
Treat these as a visual fit for this rig. Reuse the model and socket across compatible appearances;
check grip and contacts in the [construction clip](../../shared/motions/hammer/README.md).
