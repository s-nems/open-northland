# Mining pickaxe

`model/build.py` authors an oak handle and a curved, tapered iron head with facet materials.
`model/pickaxe.blend` and `model/model.glb` retain editable geometry and the render input.
This independently authored geometry is a visual approximation for the character sprite scale.

`socket.json` sets a 1.05 m length and fits the lower grip to the right palm. The mining motion fits the left hand farther
along the same shaft. Run the build script in Blender to reproduce the model, then re-export mining.
